Overleaf texAide 隐私政策

生效日期：2026 年 8 月 25 日　|　版本：3.0.0

Overleaf texAide（以下简称“扩展”）是一个由 iihciyekub 提供的 Chrome 扩展，用于辅助用户在 Overleaf、Web of Science、CNKI、DOI 页面和 Chrome 侧边栏中进行文献、TeX 和研究写作工作流操作。本政策说明扩展处理信息的方式。

简要说明：扩展不会建立开发者自己的用户账户或广告跟踪系统。设置和历史记录默认保存在用户自己的浏览器中；只有在用户主动发起功能时，必要的页面内容、查询文本或提示词才会发送到用户选择的第三方服务。

1. 扩展处理的信息

用户主动保存的设置

扩展可能在 Chrome 扩展本地存储中保存界面语言、工具显示状态、LLM 服务商和模型设置、用户输入的 API 密钥、会话历史、期刊查询历史、SID/DOI 列表以及本地下载索引。这些数据默认只保存在用户的浏览器中，扩展不会将其上传到开发者服务器。

用户主动提供的内容

当用户点击查询、转换、复制、导出或 AI 操作时，扩展可能读取相应的剪贴板文本、当前页面中用户请求处理的内容、URL、文献元数据、TeX/BibTeX/BBL 文本和用户输入的提示词。扩展不在后台持续读取剪贴板，也不会因为用户浏览页面就主动建立用户画像。

诊断信息

扩展不设置自己的分析、广告或跨网站跟踪服务。浏览器、网站和用户选择的第三方 API 可能按照各自的政策记录请求日志。

2. 信息的使用方式

  • 保存和恢复用户选择的扩展设置与本地工作记录；
  • 执行用户主动请求的文献检索、格式转换、TeX/BibTeX/BBL 处理、复制和下载操作；
  • 在用户选择并配置 LLM 服务商后，将用户主动提交的提示词以及为完成请求所需的页面上下文发送给该服务商；
  • 向用户主动选择的 Crossref、EasyScholar、机构代理、Web of Science、CNKI 或其他目标网站发出完成相应功能所需的请求。

3. 第三方服务与 API 密钥

扩展可以连接用户选择的 OpenAI 兼容服务、OpenAI、LM Studio、EasyScholar、Crossref、Web of Science、CNKI 和机构代理。扩展不控制这些服务如何处理数据；用户应阅读相应服务商的隐私政策和条款。

用户输入的 API 密钥保存在 Chrome 扩展本地存储中，并在请求相应服务时直接发送至用户选择的服务端点。开发者不会收集、出售或共享这些密钥。使用第三方服务时，用户应自行确认服务商的安全性、数据保留和跨境传输规则。

4. 权限用途

  • storage：保存用户主动配置的设置和本地历史记录。
  • clipboardRead / clipboardWrite：在用户主动点击相关操作时读取或写入文本。
  • activeTab / scripting：在用户主动操作后读取当前页面上下文并运行扩展内置脚本。
  • sidePanel：显示 Chrome 侧边栏工具界面。
  • downloads：仅在用户主动点击下载时保存用户选择的文件。
  • http/https 页面访问：在支持的网站上运行用户主动使用的页面工具；扩展不向开发者上传浏览历史。

5. 数据保留与删除

扩展本地保存的数据会一直保留到用户在扩展设置中清除、在 Chrome 中卸载扩展或清除扩展数据为止。发送给第三方服务的数据及其保留期限由相应服务商决定。用户可以删除本地历史记录、清空 API 密钥并卸载扩展；如需联系我们处理隐私问题，请发送邮件至 iihciyekub@gmail.com。

6. 儿童隐私

扩展面向一般研究和写作用户，不针对 13 岁以下儿童，也不会故意收集儿童个人信息。

7. 政策变更

如果扩展功能或数据处理方式发生重大变化，我们会更新本页面的生效日期和版本号。继续使用更新后的扩展即表示用户已查看更新内容。

Privacy Policy (English)

Overleaf texAide is a Chrome extension provided by iihciyekub for literature, TeX, and research-writing workflows on Overleaf, Web of Science, CNKI, DOI pages, and the Chrome side panel.

The extension stores user-selected settings, local history, and API keys in Chrome extension storage. It does not operate its own account, advertising, analytics, or tracking system, and it does not upload this locally stored data to the developer. When the user explicitly starts a feature, the extension may process clipboard text, page content, bibliographic metadata, TeX/BibTeX/BBL text, URLs, and prompts needed for that request.

If the user configures an AI provider or another third-party service, the relevant prompt, page context, query, or API key is sent directly to the endpoint selected by the user. Those providers control their own retention and privacy practices. The developer does not collect, sell, or share API keys. The extension does not continuously monitor the clipboard or create browsing profiles.

Users can clear local data and API keys in the extension, clear Chrome extension data, or uninstall the extension. Questions can be sent to iihciyekub@gmail.com. This policy was last updated on August 25, 2026, for version 3.0.0.
